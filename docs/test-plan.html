How to run it

  1. Run Smoke, then Sysadmin settings, so the business details are filled in first.
  2. Pair up for orders: one person orders on a phone, another works /staff on the laptop.
  3. Pay cash only. Write TEST in Special instructions on every order.
  4. On a fail, note what you saw and the order number (CAL-XXXXXX).
  5. Finish with Clean up.
